Sets and subsets

1. Toppings on a Caffè Latte

Lecture 6.1 counted orders of a hot Caffè Latte from the Starbucks online menu: 4 sizes (Short, Tall, Grande, Venti), 12 milks and 14 syrups [1]. With each syrup in or out, it found 4 × 12 × 214 = 786,432 orders. That count left out the toppings.

The same menu page lists 11 toppings for the hot Caffè Latte, in four groups [1]. The short names in the last column are used in the figures and tasks below.

The latte comes with no topping unless you ask for one [1]. This is the online menu on 4 October 2026. Several toppings, such as Pumpkin Spice Topping, are seasonal, so the list changes during the year, and a store may not carry every item.

The question: how many different ways are there to top the drink, from no topping to all 11? And when a store counts its orders, how do you count the orders that had one option or another?

Simplifications. The menu offers each topping as light, regular or extra [1]. We ignore amounts and treat each topping as on the drink or not. The menu data sets no limit on how many toppings one drink can have [1], so we assume any combination can be ordered, including all 11 at once.

Task 1 (about 5 minutes, paper)

Use only three toppings: Whipped Cream, Caramel Drizzle and Mocha Drizzle.

  1. List every different way to top the drink using only these three. Include the drink with no topping. Write the number of ways.
  2. In lecture 6.1 each syrup was a separate in-or-out choice. Use the same idea to predict the number of ways when all 11 toppings are allowed. Write the calculation you would do.
Solution to Task 1

(a) Sort the list by how many toppings are on the drink. That way nothing is missed and nothing is listed twice.

There are 8 ways. Putting Mocha Drizzle on before Caramel Drizzle gives the same drink, so order does not matter, and each pair is listed once.

(b) Each topping is in or out: 2 options for each of 11 toppings. The multiplication principle gives 2 × 2 × ⋯ × 2 with eleven 2s, which is 211 = 2048. Section 4 explains why this count is right.

2. Sets and set notation

In lecture 6.1 the result of the 14 in-or-out syrup choices was a collection of syrups, such as “Vanilla and Hazelnut”. Task 1 also produced a list of collections, this time of toppings. Mathematics has a name and a notation for a collection.

A set is a collection of different objects. The objects are the elements of the set. To write a set, list its elements between braces { }, separated by commas. Sets are usually named with capital letters. The two drizzles form a set:

D = {Caramel Drizzle, Mocha Drizzle}

Two rules for writing sets:

  • Order does not matter. {Mocha Drizzle, Caramel Drizzle} is the same set as D.
  • Each element is listed once. Writing Caramel Drizzle twice does not make a different set.

The symbol ∈ means “is an element of”, and ∉ means “is not an element of”:

Mocha Drizzle ∈ D     Whipped Cream ∉ D

The number of elements in a set A is written |A|. For the drizzles, |D| = 2.

The sizes from lecture 6.1 form a set too: S = {Short, Tall, Grande, Venti}, with |S| = 4.

In a problem, the set of everything under discussion is called the universal set, written U. In this lecture U is the set of all 11 toppings in the table in Section 1, so |U| = 11. With the short names,

U = {CP, CC, DS, TC, CK, PC, PS, SB, CD, MD, WC}

A set can also be described by a rule instead of a list. Let C be the set of toppings in U whose name contains the word “Caramel”. Checking each name in the table gives

C = {Caramel Crunch Topping, Caramel Drizzle} = {CC, CD},   |C| = 2.

3. Subsets and the empty set

A set A is a subset of a set B when every element of A is also an element of B. This is written A ⊆ B. For example:

  • D ⊆ U, because both drizzles are toppings.
  • {Whipped Cream} ⊆ U. A set with one element is still a set.
  • U ⊆ U. Every set is a subset of itself.
  • {Whipped Cream, Oatmilk} is not a subset of U, because Oatmilk is a milk, not a topping.

Each way to top the drink is a subset of U: the toppings a customer picks form a set, and each of them is in U. A latte with whipped cream and caramel drizzle has the toppings {WC, CD}.

The latte as it comes, with no topping, matches the set with no elements. It is called the empty set and is written { } or ∅. Its size is |∅| = 0. The empty set is a subset of every set, since it has no element that could fail to be in the other set.

The first question from Section 1 now has a precise form: how many subsets does U have? Task 1 answered a smaller version. The set {Whipped Cream, Caramel Drizzle, Mocha Drizzle} has 8 subsets, and one of them is ∅.

4. Counting subsets: a set with n elements has 2n subsets

Lecture 6.1 counted sets of syrups by making one in-or-out choice for each syrup. The same argument counts the subsets of any set. Build a subset one element at a time: for each element, put it in or leave it out. For the three toppings WC, CD and MD, follow any path from left to right in Figure 1 and read off the subset at its end.

By the multiplication principle from lecture 6.1, the number of paths is

2 × 2 × 2 = 8.

Different paths give different subsets, and every subset comes from exactly one path. So there are as many subsets as paths. All three “out” gives ∅; all three “in” gives the whole set.

The same reasoning works for any number of elements. A set with n elements gives n in-or-out decisions, each with 2 options:

number of subsets = 2 × 2 × ⋯ × 2 (n factors) = 2n

Elements n012345
Subsets 2n12481632

When n = 0 the set is ∅, and its only subset is ∅ itself, so the count is 20 = 1. Each new element doubles the count, because every old subset appears twice: once without the new element and once with it. This is the doubling in the running count of lecture 6.1, Task 5.

In set language, lecture 6.1 found that the set of 14 syrups has 214 = 16,384 subsets.

Task 2 (about 4 minutes, calculator)

Use the table of toppings in Section 1. For each part, show the power of 2 you use and give the answer as a number.

  1. How many ways are there to top the drink when the toppings are chosen only from the 7 in the “Topping Options” group? Count the drink with no topping.
  2. How many ways are there when the toppings are chosen from all 11? Count the drink with no topping.
  3. Of the ways in (b), how many have at least one topping on the drink?
  4. An order is a size from S, one of the 12 milks, and a set of toppings chosen from all 11. Leave syrups out. How many orders are there?
Solution to Task 2
  1. A set with 7 elements has 27 = 128 subsets, so there are 128 ways.
  2. 211 = 2048 ways. On most calculators, type 2 ^ 11 or use the xy key.
  3. Of the 2048 subsets, exactly one has no topping: ∅. Subtract the combination that is not allowed, as in lecture 6.1: 211 − 1 = 2048 − 1 = 2047.
  4. Choosing a size has 4 options, choosing a milk has 12, and choosing toppings has 211 = 2048. By the multiplication principle, 4 × 12 × 2048 = 98,304 orders.

Adding the toppings to the 786,432 orders of lecture 6.1 multiplies that count by 2048: 786,432 × 2048 = 1,610,612,736, about 1.6 billion orders.

The syrups and the toppings can also be put into one set of 14 + 11 = 25 elements. A customer’s choice of syrups and toppings is a subset of it, so there are 225 = 33,554,432 such choices. This agrees with choosing the syrups and then the toppings: 214 × 211 = 16,384 × 2048 = 33,554,432.

5. Union, intersection and complement

Three operations make new sets from old ones. The definitions use any two sets A and B. The examples use the drizzles D = {CD, MD} and the caramel toppings C = {CC, CD}, inside the universal set U of 11 toppings.

Union

The union A ∪ B is the set of elements that are in A or in B or in both. In set language, “or” includes “both”.

D ∪ C = {CD, MD, CC},   |D ∪ C| = 3

Caramel Drizzle (CD) is in both sets and is listed once.

Intersection

The intersection A ∩ B is the set of elements that are in both A and B.

D ∩ C = {CD},   |D ∩ C| = 1

When two sets have no element in common, their intersection is ∅. For example, D ∩ {WC} = ∅.

Complement

The complement A′ (read “A prime” or “not A”) is the set of elements of U that are not in A. The complement of the drizzles is every topping that is not a drizzle:

D′ = {CP, CC, DS, TC, CK, PC, PS, SB, WC}

|D′| = 9. Counting is quicker than listing: |D′| = |U| − |D| = 11 − 2 = 9.

The three operations match three everyday words, which Section 7 uses for orders:

SetWords
A ∪ BA or B (or both)
A ∩ BA and B
A′not A

Task 3 (about 5 minutes, paper)

Let T be the set of toppings in U whose full name ends with the word “Topping”. Use the table in Section 1 and the set C = {CC, CD} above. Write sets with the short names.

  1. Write T with braces and give |T|.
  2. Write C ∪ T and give its size.
  3. Write C ∩ T and give its size.
  4. Give |T′| using a subtraction, then list T′ to check.
Solution to Task 3
  1. T = {CC, CK, PC, PS, SB} (Caramel Crunch, Cookie Crumble, Pecan Crunch, Pumpkin Spice and Salted Brown-Buttery Topping), so |T| = 5.
  2. C ∪ T = {CC, CD, CK, PC, PS, SB}, so |C ∪ T| = 6. CC is in both sets and appears once.
  3. C ∩ T = {CC}, so |C ∩ T| = 1.
  4. |T′| = 11 − 5 = 6. The list: T′ = {CP, DS, TC, CD, MD, WC}.

In (b), |C| + |T| = 2 + 5 = 7, one more than |C ∪ T| = 6. The extra 1 is CC, counted once in C and again in T. Section 7 turns this into a rule.

6. Venn diagrams

A Venn diagram draws the universal set as a rectangle and each set as a circle inside it. Two overlapping circles split the rectangle into four regions:

  • inside both circles: A ∩ B;
  • inside A only;
  • inside B only;
  • outside both circles: elements in neither set.

The union A ∪ B is everything inside at least one circle. The complement A′ is everything outside circle A.

Find each of the 11 toppings in Figure 2 and check that it is in the right region. CD is in the overlap because it is both a drizzle and a caramel topping. Eight toppings are in neither set.

When a set is large, a Venn diagram shows how many elements are in each region instead of the elements themselves. Section 7 uses it that way.

7. Counting orders with inclusion-exclusion

A search for published counts of how customers customize Starbucks drinks found none, so the order counts in this section are made up for the examples.

Example (made-up numbers). One store records 200 hot Caffè Latte orders on one morning. Of these, 64 orders added at least one syrup, 50 orders used a nondairy milk (Almondmilk, Coconutmilk, Oatmilk, Soymilk or Nondairy Vanilla Sweet Cream, from the 12 milks of lecture 6.1), and 18 orders did both. How many orders added a syrup or used a nondairy milk?

Let U now be the set of the 200 orders, Y the orders with a syrup, and N the orders with a nondairy milk. Then |U| = 200, |Y| = 64, |N| = 50 and |Y ∩ N| = 18. The question asks for |Y ∪ N|.

Adding gives 64 + 50 = 114, which is too many. Each of the 18 orders with both is counted once among the 64 and again among the 50. Subtract them once so that they are counted once:

|Y ∪ N| = 64 + 50 − 18 = 96

Fill in a Venn diagram starting from the middle, so that each region holds a separate group of orders:

  1. Both: 18.
  2. Syrup only: 64 − 18 = 46.
  3. Nondairy milk only: 50 − 18 = 32.
  4. Neither: 200 − 96 = 104.

Check: 46 + 18 + 32 + 104 = 200, the total number of orders.

The same reasoning works for any two sets A and B. This rule is called inclusion-exclusion for two sets:

|A ∪ B| = |A| + |B| − |A ∩ B|

Adding |A| and |B| counts every element of A ∩ B twice, and subtracting |A ∩ B| removes the extra count. When A and B have no elements in common, |A ∩ B| = 0 and the rule is the addition principle from lecture 6.1. The rule also checks Task 3: |C ∪ T| = 2 + 5 − 1 = 6.

The complement gives the count for “not”:

|A′| = |U| − |A|

In the example, 200 − 64 = 136 orders had no syrup, and |(Y ∪ N)′| = 200 − 96 = 104 orders had neither a syrup nor a nondairy milk.

Task 4 (about 6 minutes, paper and calculator)

Made-up numbers: a store sells 150 hot Caffè Lattes in one afternoon. 44 of them had at least one item from the “Topping Options” group added. 30 had Whipped Cream added. 12 had both.

  1. How many orders had a Topping Options item or Whipped Cream?
  2. Draw a Venn diagram and write the number of orders in each of the four regions. Check that the four numbers add up to 150.
  3. How many orders had neither?
  4. How many orders had Whipped Cream but no Topping Options item?
Solution to Task 4

Let O be the orders with a Topping Options item and W the orders with Whipped Cream. Then |O| = 44, |W| = 30, |O ∩ W| = 12.

  1. |O ∪ W| = 44 + 30 − 12 = 62.
  2. Start from the middle. Both: 12. Topping Options only: 44 − 12 = 32. Whipped Cream only: 30 − 12 = 18. Neither: 150 − 62 = 88, using (a). Check: 32 + 12 + 18 + 88 = 150.
  3. |(O ∪ W)′| = 150 − 62 = 88.
  4. This is the “Whipped Cream only” region: 30 − 12 = 18.

Inclusion-exclusion is an equation with four quantities. When three of them are known, the fourth can be found by solving the equation, as in week 2.

Task 5 (about 4 minutes, calculator)

Made-up numbers: of 120 hot Caffè Latte orders, 55 added Vanilla Syrup, 40 added Caramel Crunch Topping, and 73 added at least one of the two. Find the number of orders that added both, and the number that added neither.

Solution to Task 5

Let V be the orders with Vanilla Syrup, K the orders with Caramel Crunch Topping, and x = |V ∩ K| the number that added both. Inclusion-exclusion gives

73 = 55 + 40 − x

so 73 = 95 − x and x = 95 − 73 = 22. 22 orders added both.

Neither: 120 − 73 = 47 orders.

Check with the regions: Vanilla Syrup only 55 − 22 = 33, Caramel Crunch Topping only 40 − 22 = 18, both 22, neither 47. 33 + 18 + 22 + 47 = 120.
